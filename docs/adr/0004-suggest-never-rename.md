# ADR-0004: 違反には、リネームの候補を出すが、自動では直さない

## Status
Accepted (2026-10-28)

## Context
違反を見つけても、「どう直すか」が分からなければ、利用者は 1 件ずつ考える必要がある。一方、自動で直すと、作業ファイルを意図せず変えるリスクがある([ADR-0003](0003-dry-run-by-default.md))。

## Decision
- `validate` は、違反したファイル名に、候補(`suggestion`)を付ける。ファイルは変更しない。
- 候補は、決まった小さな変換(区切りを `_` に、大文字小文字、バージョンのゼロ埋め、ショット番号のゼロ埋め、拡張子の小文字)を、組み合わせて試し、ルールのパターンに**実際に合った**最初のものだけを出す。合わなければ出さない(推測で、合わない名前を提案しない)。
- 直す作業は、人が行う(`mv`)。

## Consequences
良い: 直し方がすぐ分かり、危険な操作が増えない。候補は、パターンに合うことが保証される。
悪い: 意味を変える修正(別の名前への変更)は、提案しない。変換の組み合わせは、小さな集合に限る。
