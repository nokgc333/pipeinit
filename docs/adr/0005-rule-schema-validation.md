# ADR-0005: ルールは、読み込み時にスキーマを検証する

## Status
Accepted (2026-10-28)

## Context
ルールは、利用者が書く YAML。正規表現の誤りや、必須の項目の欠け、絶対パスは、実行の途中で、トレースバックとして現れていた。

## Decision
- 読み込み時に、構造と値を検証し、`RuleFileError` に、ファイル名と項目(`naming_patterns[0].pattern` のような位置)を含める。
- 検証するもの: `schema_version` が 1(真偽値・文字列は不可)、`folder_template` と `naming_patterns` が、辞書のリスト、各 `path` / `pattern` / `description` が空でない文字列、`pattern` が正規表現として正しい、`path` が相対パス(絶対・UNC・`~`・NUL は不可)。
- 読み込みは `yaml.safe_load` のみ(Python のオブジェクトを作らせない)。ファイルが読めない・文字コードが違うときも、同じエラーにする。
- 作成先の外へ出るパス(`..`)は、読み込み時ではなく、作成時に(シンボリックリンクの解決後で)検査する(終了コード 6)。

## Consequences
良い: ルールの誤りが、原因つきの 1 行で分かる。トレースバックが出ない。
悪い: 正規表現そのものの危険(ReDoS)は、検査しない。ルールは、信頼できるファイルとして扱う前提。
