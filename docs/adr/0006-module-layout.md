# ADR-0006: CLI を、定義・処理・表示・メッセージ・終了コードに分ける

## Status
Accepted (2026-10-28)

## Context
`cli.py` に、コマンドの定義・処理・メッセージ・終了コードが混在し、保守性が低かった(指数 49)。オプション(`--json`・`--quiet`・`--lang`)を足すたびに、膨らむ。

## Decision
| モジュール | 責務 |
| --- | --- |
| `cli.py` | click のコマンド・オプションの定義だけ。共通オプション、設定の読み込み、終了 |
| `commands.py` | 各コマンドの処理。終了コードを返す(`sys.exit` を呼ばない)。テストしやすい |
| `presenter.py` | 出力(通常・JSON・色・`--quiet`・`--verbose`)。結果は標準出力、詳細は標準エラー |
| `messages.py` | 日本語・英語のカタログと、言語の決定。2 言語の項目とプレースホルダーが一致することを、テストが確かめる |
| `exit_codes.py` | 終了コードの定義と表(`--help` と README の元) |

依存は、`cli → commands → presenter → messages` の一方向。ファイル操作の安全は `fsutil` / `templates` に閉じる。JSON の出力は、言語に依存しない。

## Consequences
良い: `cli.py` の保守性指数が 64、複雑度は据え置き。出力の形を変えても、処理のテストに影響しない。
悪い: モジュールが増える(5 つ)。メッセージを足すときは、2 言語を書く必要がある。
