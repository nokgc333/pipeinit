# 大きなフォルダでの計測

`validate` は、ファイルを 1 つずつ走査し(`os.scandir` の深さ優先、全件を一度にメモリに持たない)、違反だけを覚える。メモリは、ファイル数ではなく、違反の数に比例する。

> 計測日: 2026-10-28 / 環境: macOS(Apple Silicon)、Python 3.12、`tracemalloc` 有効(実行はその分、遅くなる)

| ファイル数 | フォルダ数 | 違反 | 時間 | メモリのピーク |
| ---: | ---: | ---: | ---: | ---: |
| 200,000 | 200 | 20,000 | 10.2 秒 | 7.1 MB |

- 時間は、ファイル数にほぼ比例する(1 ファイルあたり約 50 マイクロ秒)
- 隠しフォルダ(`.git` など)とシンボリックリンクのフォルダは辿らない(循環と、外への脱出を避ける)
- 読めないフォルダは、飛ばして続ける

再現: 200 個のフォルダに 1,000 ファイルずつ作り、`validate_directory` を実行する(テストの `tests/test_file_safety.py` が、走査の規則を固定している)。
